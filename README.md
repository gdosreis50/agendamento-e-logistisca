Este projeto foi desenvolvido para apoiar a operação logística, garantindo conformidade operacional e legal e mantendo a produtividade.

A solução consiste em manter sob controle do operador logístico os carregamentos agendados, a conformidade legal e operacional do veículo e motorista com o transporte a ser feito, e a ordem de carregamento mais adequada. 
Para tanto, ainda contempla cadastro e manutenção de motoristas, veículos, vagões e transportadoras.

É possível:
  - Cadastrar, editar, consultar e excluir:
      - Motoristas;
      - Veículos e seus vagões;
      - Funcionários;
      - Transportadora;
      - Agendamentos de carregamento.

  - Consultar pedidos disponíveis para carregamento;
  - Ao adicionar a fila de carregamento, emitir documento de checklist e aceite;
  - Retirar carregamentos da fila para concluir carregamento.

Este projeto consome API desenvolvida no repositório "agendamento-e-log-stica", sendo apenas um app cliente. Outros apps/sites podem ser desenvolvidos a partir daqui.
